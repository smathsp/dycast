# DyCast 26.9.15 项目说明

DyCast 是一款面向抖音直播间的 Windows 桌面弹幕互动工具。它连接直播间弹幕 WebSocket，解析并展示聊天、礼物、点赞、进场等消息；同时提供 WebSocket 转发、弹幕互动大屏、自动抽奖、直播顶部信息条、音频和 AI 精选等能力。

Windows 正式发布物仅为一个 x64 免安装单文件 EXE，可从 [GitHub Releases](https://github.com/smathsp/dycast/releases/latest) 下载，不提供安装程序。升级时替换 EXE 即可，普通设置会从电脑公共目录继续读取。

> 本项目依赖直播平台的网页接口与消息协议。接口或协议变更、网络环境、登录状态等都可能影响连接结果。请仅将它用于合法、合规的直播互动场景。

## 功能概览

- 输入直播间房间号或直播链接，获取直播间信息并实时接收弹幕。
- 分类展示聊天、会员表情、礼物、点赞、进场、关注与直播状态消息；连接异常时自动重连。
- 将整理后的弹幕 JSON 批量转发到自定义 `ws://` 或 `wss://` 服务端。
- 支持保存本场弹幕记录与房间历史记录。
- 提供独立的「弹幕充能大屏」：收集聊天弹幕、展示弹幕墙、能量达到阈值后自动抽奖并保留中奖历史。抽奖阈值最低为 10 条，不再以“未中过奖”作为参与条件，同一用户可以跨轮再次中奖。
- 提供独立的观众弹幕侧边栏和可置顶、可放大的精选弹幕窗口，适合 OBS、直播伴侣等软件进行窗口采集。侧边栏默认置顶，只负责显示，不参与抽奖计数。
- 提供独立的绿幕直播顶部信息条：左侧显示剩余中奖名额，右侧显示 `HH:MM:SS` 直播倒计时；主界面可直接修改数据并开始、暂停、重置倒计时。采集窗口名称固定为「直播顶部信息条（绿幕采集） - 抖音弹幕姬」，首次打开自动位于当前屏幕顶部。
- 可管理充能、开奖和中奖三个场景的本地音频；支持导入、删除、打包分享和恢复音频包。
- 可选的 AI 精选弹幕：使用 OpenAI Chat Completions 兼容接口筛选值得主播回应的问题，并先在本机过滤广告、辱骂和敏感内容。

## 环境要求

- Node.js 22（项目约束为 `>=22 <25`）与 npm 10 或更高版本。
- Electron 44（当前依赖为 Electron 44.3.x）。
- npm。
- Windows：用于完整的 Electron 桌面体验及打包；浏览器模式也可用于前端调试。

## 快速开始

安装依赖：

```bash
npm install
```

启动桌面端：

```bash
npm run electron:dev
```

此命令会先进行类型检查与前端构建，再启动 Electron。Electron 会同时启动本地代理服务，默认监听 `15173` 端口。

仅调试浏览器前端：

```bash
npm run dev
```

Vite 开发服务器默认提供 `/dylive` 和 `/socket` 代理，以便在开发时访问直播间 HTTP 与 WebSocket 接口。

## 使用方式

1. 启动应用，在「房间号」中输入房间号或抖音直播链接，点击连接。
2. 连接成功后，在中间区域查看聊天和礼物；右侧区域显示点赞、进场、关注和状态提示。
3. 如需向自己的服务转发数据，在「WS 地址」中填写服务端地址，点击转发。
4. 点击底部工具栏的闪电图标打开弹幕充能大屏；点击气泡图标打开观众弹幕侧边栏。
5. 打开直播顶部信息条后，在主界面快捷区直接编辑倒计时和剩余中奖名额。直播伴侣添加窗口采集时选择「直播顶部信息条（绿幕采集） - 抖音弹幕姬」。
6. 在设置中调整礼物置顶、抽奖阈值、关键词、灯牌条件、防刷、音频和 AI 精选等选项。能量达到阈值且仍有中奖名额和符合条件的弹幕后会自动抽奖。

### 弹幕转发格式

转发端会收到一个 JSON 数组，数组元素为 `DyMessage`。常用字段如下：

```ts
interface DyMessage {
  id?: string;
  method?: string; // 例如 WebcastChatMessage、WebcastGiftMessage
  user?: { id?: string; name?: string; avatar?: string };
  content?: string;
  gift?: { id?: string; name?: string; price?: number; count?: number | string };
  room?: {
    audienceCount?: number | string;
    likeCount?: number | string;
    followCount?: number | string;
    totalUserCount?: number | string;
  };
  time?: number;
}
```

一次收到的多条新消息会合并为同一个数组发送。消费端应兼容未知字段与尚未支持的消息类型。

需要快速验证转发时，可安装 Python `websockets` 后运行 `examples/websocket-receiver.py`，再将应用转发地址设为 `ws://localhost:8765`。

### AI 精选弹幕

在设置中开启 AI 精选后，填写兼容 OpenAI Chat Completions 的接口地址、模型名和 API Key。默认接口格式为：

```text
POST /v1/chat/completions
```

Electron 中的 API Key 使用系统安全存储加密保存，并与当前 API 服务域名绑定；浏览器调试模式仅在当前会话内保留。仍建议使用权限最小化、可单独撤销的密钥。除本机 `localhost` 接口外，应用要求 AI 接口使用 HTTPS。

├─ src/

│  ├─ views/                # 主控制台、弹幕大屏、观众展示、精选弹幕窗口

## 架构与数据流

```text
抖音直播间
  │ HTTP / WebSocket
  ▼
本地代理（Vite 开发代理或 server.cjs）
  ▼
src/core/dycast.ts
  ├─ 获取房间与 IM 信息、生成连接参数
  ├─ 解压并解析 PushFrame / Response / 各类消息
  ▼
IndexView.vue
  ├─ 主界面分类展示与本场记录
  ├─ RelayCast → 用户自定义 WebSocket 服务
  └─ Electron IPC → 只转发一份弹幕，不在主页累计抽奖状态
         ├─ 弹幕大屏窗口 → 唯一的能量计数、候选池和抽奖状态所有者
         └─ 侧边栏窗口 → 仅展示弹幕，不累计能量、不创建奖池
```

Electron 环境下，主页收到弹幕后只通过 IPC 转发一次。弹幕大屏窗口是能量计数与抽奖状态的唯一所有者，侧边栏以只读展示模式接收消息，从而避免同一条弹幕被重复计数或触发两次抽奖。音频导入、音频包和图片读取也由主进程处理，以避免渲染进程直接访问本地文件系统。

直播顶部信息条是另一独立窗口，使用绿幕背景并保持固定宽高比；窗口位置和大小会随普通设置保存，重新打开应用后继续沿用。

## 本地数据与安全

- Electron 的普通设置统一保存在 Windows 公共目录 `%PUBLIC%\Documents\DyCast\settings.json`（通常为 `C:\Users\Public\Documents\DyCast\settings.json`）；升级、替换免安装 EXE 或更换程序所在目录后都会继续读取。浏览器模式仍使用 `localStorage`。
- 设置采用合并写入并保留未来版本未知字段；`settings.previous.json` 保存最近一次有效备份。主设置损坏时会先保存损坏快照，再尝试从最近备份恢复，降低断电或写入中断造成的配置丢失风险。
- 旧版 `localStorage`、显示器选择和音频目录会在首次启动时迁移到公共设置体系。普通设置迁移不会要求用户重新配置。
- 自定义音频保存在公共目录的 `audio/` 子目录，应用提供导入、删除和 ZIP 音频包导入/导出功能。
- AI API Key 不写入公共 JSON。它由 Electron `safeStorage` 加密后保存在当前 Windows 用户自己的 Electron 应用数据目录，其他本机用户不能通过公共设置覆盖。旧版公共目录中的有效加密凭据会在当前用户能够解密时自动迁移并移除旧文件；迁移失败时会保留旧文件，避免凭据丢失。
- 不要将 API Key、Cookie、直播间账号信息或包含这些信息的本地数据提交到仓库。
- 直播接口返回的数据应按不可信输入处理；转发服务需要自行实施鉴权、频率限制和日志脱敏。

## 故障排查

### 无法连接直播间

- 确认房间号、链接和直播状态有效。
- 检查网络、系统代理或 VPN/TUN 设置；桌面端会优先使用 Electron 的网络栈。
- 平台消息协议或签名策略变化时，旧版本可能无法连接，需要更新解析实现。

### 转发端收不到数据

- 确认转发地址以 `ws://` 或 `wss://` 开头，且服务端已监听。
- 先确认主直播间已经连接成功；主连接断开时应用会停止转发连接。
- 服务端应按 JSON 数组处理消息，而不是假设每次只有一条弹幕。

### AI 精选没有结果

- 检查接口地址、模型名、密钥与网络连通性。
- 候选弹幕会先经过本地价值与安全过滤；没有符合条件的提问时，返回空结果是正常行为。
- 仅本机接口可使用 HTTP，远程接口必须使用 HTTPS。
